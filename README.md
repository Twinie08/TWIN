# Scadlar

*Schedule, Class, Homework, Online Activity Reminder*

Scadlar is a web app that helps high school and college students keep track of their schedules, classes, homework and online activities, and reminds them before the deadline.

## Features

- Sign up and log in
- *Schedule*: pick a day from Monday to Saturday and a time
- *Class*: subject, time and room
- *Homework*: subject and title
- *Online Activity*: subject and title
- Reminders before the due time (at the time, 10 minutes, 30 minutes, 1 hour or 1 day before)
- Mark items as done or delete them
- Filter the list by category
- Baby pink and black design

## Built with

- HTML
- CSS
- JavaScript

## How to use

1. Open the live site: https://twinie08.github.io/TWIN/
2. Sign up, then log in.
3. Choose a category, fill in the details and click *Add*.
4. Allow notifications (the bell icon) so reminders can pop up.

## Files

- index.html: the page structure
- style.css: the design
- script.js: login, items and reminders
